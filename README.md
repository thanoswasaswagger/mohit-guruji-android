# Mohit Guruji Android

Premium Android app for https://www.mohitguruji.com/home.

This project provides a polished Android WebView experience with a branded launch screen, secure HTTPS-only loading, cookies/session support, file upload support, downloads, offline/error recovery, external-link handling, and GitHub Actions APK builds.

## Build
Push to `main` or run the `Build Android APK` workflow. The workflow creates an installable debug APK and uploads it as `Mohit-Guruji-Android-APK`.

- Package: `com.mohitguruji.app`
- Minimum Android: 7.0 (API 24)
- Target/compile SDK: 35
- Start URL: `https://www.mohitguruji.com/home`
